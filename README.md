# Academic ML Predictor & Student Success Hub

Studi kasus interaktif dan dashboard analisis berdasarkan materi kuliah praktisi *Informatics Practitioner Lecture Series* Universitas Bengkulu dengan tema **"Introduction to Machine Learning"** yang disampaikan oleh **Dr. Taniza binti Tajuddin** (Senior Lecturer, Faculty of Computer and Mathematical Sciences, Universiti Teknologi MARA Cawangan Kedah, Malaysia).

## 🛠️ Fitur & Modul Utama
- **Paradigma Machine Learning:** Memahami pergeseran dari pemrograman tradisional berbasis aturan (*rule-based thinking*) menuju pembelajaran berbasis data (*data-driven thinking*).
- **Kategori Pembelajaran Mesin:** Eksplorasi mendalam mengenai *Supervised Learning* (Klasifikasi & Regresi), *Unsupervised Learning* (Clustering), hingga *Reinforcement Learning*.
- **Simulasi Prediksi Akademik:** Fitur interaktif untuk mensimulasikan prediksi kelulusan mahasiswa berdasarkan jam belajar, persentase kehadiran, dan nilai tugas.
- **Tahapan Alur Kerja Data (*Data Workflow*):** Dokumentasi langkah sistematis mulai dari pengumpulan data, prapemrosesan (*cleaning missing values*), pembagian data latih/uji (*train-test split*), hingga evaluasi metrik model.
